# Generated figures

These figures are generated by `notebooks/01_compare_peak_detectors.ipynb` and
referenced from Markdown cells so they remain visible in GitHub's notebook
preview without embedding large base64 outputs in the notebook JSON.

Regenerate the notebook and figures from the repository root with:

```bash
python scripts/build_notebook.py
python scripts/execute_notebook_inprocess.py notebooks/01_compare_peak_detectors.ipynb
python scripts/build_notebook.py
```

The final build command removes embedded notebook outputs while retaining the
generated PNG files.
